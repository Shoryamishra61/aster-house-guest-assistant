# Aster House Guest Assistant - Design System Specification

## 1. Visual Philosophy: Quiet Hospitality

Aster House translates quiet, restrained boutique hotel service to digital interaction. It deliberately rejects generic tech tropes:
- **No** purple or cyan glowing gradients.
- **No** decorative glassmorphism or floating translucent orbs.
- **No** robotic avatars or sparkling "AI Magic" badges.
- **No** false typing delays for theater.

---

## 2. Core Tokens & Palette

| Token | Value | Semantic Role |
| :--- | :--- | :--- |
| `surface-bg` | `#F7F5F0` | Warm parchment background |
| `surface-card` | `#FFFFFF` | Crisp card and container surface |
| `border-subtle` | `#D8D5CE` | Warm neutral hairline borders |
| `text-primary` | `#1E2328` | Charcoal high-legibility body text |
| `text-muted` | `#66707A` | Slate secondary labels and metadata |
| `brand-deep` | `#1F5A5A` | Deep evergreen primary button and accent |
| `alert-error` | `#9A3412` | Terra cotta error border and alert text |
| `alert-bg` | `#FDF2EC` | Warm peach error container background |

---

## 3. Typography Scale

- **Title / Hero**: `1.125rem (18px)`, SemiBold, tracking `-0.02em`
- **Section Headers**: `0.875rem (14px)`, Medium/SemiBold
- **Body Text**: `0.875rem (14px)`, Regular, leading `1.5`
- **Metadata / Provenance**: `0.6875rem (11px)`, Regular / Medium
