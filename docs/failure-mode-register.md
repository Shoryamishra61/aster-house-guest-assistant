# Aster House Guest Assistant - Production Failure Mode Register

| Failure ID | Failure Mode | Why It Matters | Control Introduced | Where Implemented | How Tested | Operational Signal | Fallback / Recovery |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **FM-01** | Model provider outage / 500 error | Blocks all guest conversations if chatbot relies 100% on external LLM | Fallback hierarchy & bounded timeout | `src/server/orchestrator/router.ts` | `chat.test.ts` & `productionSubsystems.test.ts` | Log event: `intent_classification_failed`, `errorCode: LLM_TIMEOUT` | Return deterministic FAQ response from verified KB; offer front-desk phone |
| **FM-02** | Hallucinated room rates or capacity | Exposes hotel to booking disputes or overbooking legal liabilities | Strict deterministic availability domain & zero-LLM pricing authority | `src/server/domain/availability.ts` | `domain.test.ts`, invariant tests | Telemetry: `route: availability_tool`, `toolCalls: 1` | Room results generated strictly by pure domain calculation; LLM never originates price |
| **FM-03** | Prompt injection in chat input | Attacker commands model to reveal secrets or authorize free stays | Deterministic classification boundaries & claim verification | `src/server/retrieval/verifier.ts`, `router.ts` | `E2E-03`, `chat.test.ts` | Intent: `out_of_scope`, `isFallback: true` | Model output verified against raw JSON facts; ungrounded claims stripped/rejected |
| **FM-04** | Prompt injection in uploaded document | Malicious policy file attempts to hijack knowledge base rules | Document treated as untrusted text; candidate facts require operator review | `src/server/domain/knowledgeGovernance.ts` | `productionSubsystems.test.ts` | Status: `[SUSPICIOUS INJECTION]`, held in review | Human supervisor approval gate in `/ops`; never auto-publishes |
| **FM-05** | Conflicting hotel policies uploaded | Operator uploads PDF stating checkout is 12 PM while KB says 11 AM | Ingestion conflict detection engine | `src/server/domain/knowledgeGovernance.ts` | `productionSubsystems.test.ts`, `/ops` UI | Severity: `high`, reason recorded in `conflicts[]` | Flags discrepancy in review queue; previous verified version remains active |
| **FM-06** | Accidental publication of incorrect policy | Wrong parking rate published live to guests | Immutable versioning and instant rollback | `src/server/domain/knowledgeGovernance.ts`, `/ops` | `productionSubsystems.test.ts` | Knowledge version increment; audit event | Single-click rollback in `/ops` to previous verified version number |
| **FM-07** | Floating-point currency rounding errors | Cents truncation across multi-night stays creates penny mismatches | Minor-unit integer `Money` value object (`amountMinor`) | `src/server/domain/money.ts` | `productionSubsystems.test.ts` | Minor unit validation at domain boundaries | Throws on non-integer cents; strict multiplication |
| **FM-08** | Browser / server timezone mismatch | Guest booking across midnight or DST boundary sees shifted check-in date | Hotel property timezone concept (`property.timeZone`) & UTC date-only math | `src/server/domain/hotelTime.ts` | `productionSubsystems.test.ts` | `getTodayAtProperty()` formatted in property local time | Dates handled as calendar strings `YYYY-MM-DD` |
| **FM-09** | PII leakage in structured logs | Guest phone, email, or credit card logged to disk or observability tools | Regex sanitization filter for telemetry | `src/server/security/pii.ts`, `logger.ts` | `productionSubsystems.test.ts` | Log tokens replaced with `[REDACTED_EMAIL]`, `[REDACTED_PHONE]` | Sensitive keys scrubbed recursively |
| **FM-10** | Request duplicate / browser retry abuse | Rapid double-click on availability search duplicates requests | Idempotency caching layer on chat API | `src/app/api/chat/route.ts` | `productionSubsystems.test.ts` | Response header: `X-Cache: HIT-IDEMPOTENT` | Cached response returned immediately |
| **FM-11** | Public API flood / DoS abuse | Automated script exhausts server resources or token budget | Sliding-window token bucket rate limiter | `src/server/security/rateLimiter.ts` | `productionSubsystems.test.ts` | HTTP 429 Too Many Requests with `Retry-After` header | Client informed to wait; backend protected |
| **FM-12** | Unexpected PMS / tool degradation | Availability lookup service crashes or degrades | Operational kill switches & circuit breaker | `src/server/security/featureFlags.ts`, `/ops` | `productionSubsystems.test.ts`, `route.ts` | Flag: `availabilityProviderEnabled = false` | Explains temporary maintenance and offers direct phone contact |
